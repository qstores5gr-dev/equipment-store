# දිනය ලෙජරය අයිතමය සීරියල් අංකය නාමාවලි අංකය වත්කම් අංකය මුළු ප්‍රමාණය නිකුත් ප්‍රමාණය ඉතිරිය නිකුත් කළ ස්ථානය පානු පාසු ක්‍රියාමාර්ග

දැනට ඇතුළත් කළ දත්ත කිසිවක් නොමැත.

Google Sheets සෘජු සම්බන්ධතාවය (Integration)

මෙම වෙබ් අඩවිය හරහා ඇතුළත් කරන සියලුම දත්ත ඔබේ Google Sheet එකේ අදාළ Tab 9 ට ස්වයංක්‍රීයව Save වීමට පහත සැකසුම් සකසන්න.

Google Sheet එක සකස් කරගන්නා ආකාරය (පියවරෙන් පියවර):

  1. අලුත් **Google Sheet** එකක් සාදා එහි නම **"උපකරණ ගබඩාව - 5 ගජබා"** ලෙස යොදන්න.
  2. එහි පහළින් Tabs (පිටු) 9 ක් සාදා පහත නිවැරදි නම් ලබා දෙන්න: බැරැක්ක භාණ්ඩ ලෙජරය, පාලන උපකරණ ලෙජරය, උපකරණ ලෙජරය, සංඥා ලෙජරය, ක්‍රීඩා භාණ්ඩ සහ සුභසාධක ලෙජරය, යාන්ත්‍රික ප්‍රවාහන ලෙජරය, සිතියම් ලෙජරය, පවිත්‍රතා/ක්‍ෂය ද්‍රව්‍ය ලෙජරය, ඒකක දේපල ලෙජරය
  3. සෑම Sheet එකකම 1 වන පේළියේ (Headers) මෙම මාතෘකා 12 ලියන්න: දිනය | ලෙජරය | අයිතමය | සීරියල් අංකය | නාමාවලි අංකය | ස්ථාවර වත්කම් අංකය | ප්‍රමාණය | නිකුත් කිරීම් ප්‍රමාණය | නිකුත් කර ඇති ස්ථානය | ගබඩාවේ ඉතිරිය | පානු | පාසු
  4. Google Sheet හි **Extensions > Apps Script** වෙත ගොස් එහි ඇති Code එක ඉවත් කර පහත සූත්‍රය Copy-Paste කරන්න:
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getSheetByName(data.ledger);
    if (!sheet) {
      sheet = ss.insertSheet(data.ledger);
      sheet.appendRow(["දිනය","ලෙජරය","අයිතමය","සීරියල් අංකය","නාමාවලි අංකය","ස්ථාවර වත්කම් අංකය","ප්‍රමාණය","නිකුත් කිරීම් ප්‍රමාණය","නිකුත් කර ඇති ස්ථානය","ගබඩාවේ ඉතිරිය","පානු","පාසු"]);
    }
    sheet.appendRow([
      data.date, data.ledger, data.item, data.serial, data.catalog,
      data.asset, data.totalQty, data.issuedQty, data.location,
      data.balance, data.panu, data.pasu
    ]);
    return ContentService.createTextOutput(JSON.stringify({result: "success"})).setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({result: "error", error: err.toString()})).setMimeType(ContentService.MimeType.JSON);
  }
}

  2. **Who has access** කියන තැනට **"Anyone"** ලබා දී Deploy කර එහි ලැබෙන Webhook URL එක Copy කර ඉහත කොටුවට පේස්ට් (Paste) කරන්න.
